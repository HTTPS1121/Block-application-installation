# שומר אפליקציות (AppGuard)

אפליקציית אנדרואיד (יעד: Pixel / AOSP) שחוסמת פתיחת אפליקציות לא מורשות — **בלי Device Owner**.

השראה התנהגותית: Kaspersky Safe Kids על Pixel (שכבת Accessibility + PIN), לא Knox.

## מצב הגנה יחיד

**רשימה מותרת** — רק אפליקציות מסומנות נפתחות. אין «רמה 2» ואין תור ממתין לאישור.  
אפליקציה חדשה פשוט לא ברשימה → חסומה עד שתסומן כמותרת.

בנוסף: **הגנה עצמית** — מקשה על הסרה / ביטול מנהל מכשיר / כיבוי נגישות בלי קוד ניהול.

## איך זה עובד

- Accessibility — זיהוי מיידי + BACK / מסך PIN
- UsageStats (Foreground Service) — גיבוי לזיהוי אפליקציה בחזית
- Overlay — מסך חסימה
- Device Admin — מקשיח הסרה; ניסיון ביטול → PIN
- אחרי Setup + «אשר» ברשימה — ההגנה וההגנה העצמית נדלקות יחד

## הגנה עצמית (בקצרה)

| פעולה | התנהגות |
|--------|---------|
| פרטי אפליקציה (כל האפליקציות, כולל השומר) | מותר לפתוח |
| «הסרה» רק בפרטי **שומר אפליקציות** | לא עוברת → מסך PIN |
| ביטול מנהל המכשיר / כיבוי נגישות של השומר | BACK → מסך PIN |
| לחיצה ארוכה על אייקונים במסך הבית | לא מפעילה PIN |
| PIN נכון | ~45 שנ׳ להשלמת הסרה/ביטול במערכת |

## הרשאות באשף

| הרשאה | למה |
|---|---|
| Accessibility | חסימת אפליקציות + הגנה עצמית |
| Usage Access | ידיעת האפליקציה בחזית |
| Device Admin | הקשיית הסרה |
| Display over other apps | מסך חסימה |
| Ignore Battery Optimizations | שירות רקע |
| Notifications | התראת Foreground Service |
| OEM Auto-start | לפי יצרן |

## בנייה

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

## הפעלה

1. התקן → הגדר קוד ניהול (+ שמור קוד שחזור)
2. אשף הרשאות — הפעל הכול
3. בחר אפליקציות מותרות → **אשר** (חימוש)
4. להסרה יזומה: הגדרות באפליקציה → שחרור נעילת הסרה (עם הקוד) → ~45 שנ׳
