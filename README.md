# AppGuard / שומר אפליקציות

אפליקציית אנדרואיד (target API 37 / Android 17) שמונעת פתיחת אפליקציות לא מורשות וחוסמת התקנות חדשות, עם קוד ניהול ומניעת הסרה.

## מה האפליקציה עושה

1. **רמה 1 – רשימה מותרת**: חוסמת פתיחת אפליקציות שלא סומנו כמותרות (שירות נגישות).
2. **רמה 2 – חסימת התקנות**: חוסמת מסכי התקנה (Play Store / Package Installer). עם Device Owner גם נחסמת התקנה ברמת המערכת.
3. **קוד ניהול**: בכניסה ובהגדרות.
4. **מניעת הסרה**: מנהל מכשיר (Device Admin). בלי שחרור קודם מהאפליקציה – אנדרואיד לא מאפשר הסרה, ומוצגת הודעה.

## התקנה ובנייה

```bash
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleDebug
```

ה-APK: `app/build/outputs/apk/debug/app-debug.apk`

## הפעלה במכשיר

1. התקן את ה-APK.
2. פתח את האפליקציה והגדר קוד ניהול (4–8 ספרות).
3. לחץ **הפעל הגנת הסרה** ואשר מנהל מכשיר.
4. לחץ **הפעל מעקב אפליקציות** והפעל את שירות הנגישות של "שומר אפליקציות".
5. הפעל רמה 1 ו/או רמה 2, ובנה רשימה מותרת.

## שחרור להסרה

הגדרות > **שחרר נעילת הסרה** (אחרי כניסה עם הקוד) > אחר כך אפשר להסיר מהגדרות המכשיר.

## Device Owner (חסימת התקנה חזקה יותר)

דורש איפוס מכשיר / provisioning. אחרי התקנת האפליקציה:

```bash
adb shell dpm set-device-owner com.appguard.blocker/.admin.AppDeviceAdminReceiver
```

אז `DISALLOW_INSTALL_APPS` נאכף ברמת המערכת כשרמה 2 דולקת.

## הערות

- בלי Device Owner, חסימת התקנה מבוססת על שירות נגישות (חסימת UI התקנה) + התראה אם חבילה בכל זאת הותקנה.
- מנהל מכשיר רגיל מונע הסרה; ביטול מנהל מהגדרות המערכת מציג אזהרה בעברית, והשחרור המומלץ הוא רק דרך האפליקציה עם הקוד.
